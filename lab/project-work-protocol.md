## Operations

- `Where is Type.Member() defined?` uses zero parameters. `Where is Type.Member(int) defined?` uses the C# declaration's written parameter types. `Where is Type.Member(1 parameter) defined?` selects by declared arity and includes Python receiver parameters. The initial C# subset covers ordinary nongeneric methods and simple by-value type spellings. Ambiguous matches withhold. Code follow-ups retain the exact selected declaration.
- `Where is Type.Member(int) called?` returns source-bound C# invocation spans in other imported files, with the selected declaration as supporting context. This is a bounded view of compiler-bound calls and may exclude calls requiring dynamic dispatch or additional build context. When none can be verified it withholds. Up to eight evidence passages per task includes the declaration. Python call resolution remains outside the evaluated subset.
- `Compare project claims: key one | key two` requests two to four literal keys from authorized local TXT/Markdown claims. A supported result requires at least two active documents and at most eight matching passages. Record the individual status and exact provenance of each key. A conflicting, expired, or unconfirmed key withholds completion. Changed selected evidence between proposal and delivery withholds. Compare this bounded extractive operation with exact field search.
