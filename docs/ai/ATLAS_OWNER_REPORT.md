# Owner report

**A working local ATLAS Next desktop candidate is ready for independent review.** Extract the ZIP and open ATLAS Next.cmd. Ask a handbook question, compare the real model recommendation with the active rule, verify the result and export a receipt. A completed task survives restart, and a stopped or interrupted task shows its true state. The library includes two facts and one procedure about archive and export handling.

Astra changed the production runtime from WPF plus Python to a WPF/C# host with local CPU inference. The lab uses Python and NumPy. This reduced packaging and lifecycle complexity for the first fixed-size model. No external pretrained model, API, account or GPU participates in the release. The system trains an original narrow policy and uses it only in shadow mode. It tied the simpler learned baseline on the public test set. Stronger evidence and independent evaluator custody are necessary for promotion.

The portable Windows x64 package includes a private runtime and starts without Python. It is unsigned. Author tests cover real desktop, source verification, checkpoint loading, termination/recovery, basic cancellation and packaging. Windows denied the guest configuration query, and the application exposes no untrusted execution. Guest work requires separately authorized provisioning and independent containment review. The original repository is outside this product's source, build and runtime dependencies.
