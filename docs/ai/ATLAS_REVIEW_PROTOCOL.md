# Five-update development and independent review

Sol independently reviews Argon's frozen contribution when applicable, commits a separate verdict, and author-verifies any required repair before using it as a provisional dependency. The last independently accepted product remains explicitly identified.

Each Sol batch targets five substantial, individually useful updates. Define measurable criteria and preregister comparisons where applicable. Freeze each product and record its evidence separately. Validate dependency gates before implementation and exercise the full system before handing the batch to Argon. Record incomplete work precisely if a gate or dependency prevents completion.

Argon reviews each frozen update and any provisional repair, then reviews the integrated system in one activation. Record per-update verdicts and one consolidated repair register. No author accepts their own work. Promotion of a dependent update requires acceptance of its prerequisites.

The canonical handoff controls the single writer. Keep protected evaluation inputs and labels outside Git and unavailable to training. Authorization stays explicit. Executable automation stays disabled and models stay in shadow until separately qualified and authorized. The owner relays the short continuation prompt.
