# Reciprocal review and implementation

GPT-6.2 Sol Extra High and Gemini Argon Orchestrator alternate as author and independent reviewer. The canonical handoff assigns the current phase and the only writer for the product worktree and handoff. The owner activates the assigned agent with a short continuation prompt. The agents maintain the technical assignment in the handoff.

## Review and continue

1. Read the canonical handoff and verify the actual Git branch, frozen product, author evidence revision, prerequisites and working tree. Review in a clean independent checkout. Keep protected inputs and labels in evaluator custody. Rerun the required checks, compare behavior and independently verify the candidate's claims.
2. Commit the independent verdict, custody-safe receipt and owner report separately from product code. A reviewer may accept only a candidate authored by the counterpart. Preserve the earlier reviewers' records and decisions.
3. If repairs are required, assign a specific bounded repair and regression tests to the original author. Pause feature development until independent acceptance.
4. Upon acceptance, use the frozen accepted product as the next baseline. Select the next bounded milestone using the roadmap, measured outcomes and reviewer findings. Record scope, tests and boundaries before touching product code. Preregister the comparison where required.
5. Implement the next assignment in the same activation when authorized and feasible. Commit product and evidence separately. Record exact revisions, commands, results, limitations and next reviewer in the canonical handoff. If blocked, record the exact incomplete state and remaining checks for resumption.

## Owner relay

Provide a short copy-ready prompt naming the counterpart and directing them to the canonical handoff. The owner relays it. Session messaging, UI handoff, polling for another agent and unattended agent loops are outside this workflow.

The first reciprocal transfer is Sol's NEXT-007 candidate to Argon. Upon acceptance Argon develops NEXT-008 and assigns its review to Sol. Upon acceptance Sol develops NEXT-009. Continue alternating under this protocol.
