# Product vision

ATLAS learns specialized decisions, retrieves facts and procedures from inspectable files, and checks whether its decisions improve verified outcomes. The first product demonstrates a bounded instance of that loop. The host owns permission, resource limits, execution and verification. Model origin and qualification travel with every proposal.

The first original model advises the Primary coordinator on fact, procedure or clarification. The Engineering and Execution capability will propose scoped technical actions. Research and Verification will assess evidence sufficiency and propose checks. All three should use the same task/receipt lifecycle. Only the Primary routing experiment exists in this release. Deterministic software remains active where it delivers a qualified, bounded operation. ATLAS-adapted and external-reference implementations require separate recorded lineage if introduced.

Success means demonstrable task completion on new project families under equal resources, fewer reference-assisted completions at matched quality, and auditable safe abstention. An accurate synthetic classifier is an experiment. Independent evaluation and owner authority are needed for deployment of a learned routing policy. [Current result](ai/ATLAS_OWNER_REPORT.md)
