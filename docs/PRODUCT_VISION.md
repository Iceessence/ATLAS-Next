## PLATZ Technologies and ATLAS AI

PLATZ Technologies is the overarching technology and creative-development ecosystem. ATLAS AI is its local-first intelligence product for reasoning, research, coding, knowledge navigation, authorized automation and verified self-improvement. PLATZ Engine is a separate, early-stage creation platform with PLATZ Studio, Core, Runtime and Hub. Its own `PLATZ_MASTER.md` governs the engine. Its design calls for Vulkan-first, GPU-first rendering, a CPU reference and OpenGL fallback, editable canonical project data, visual and code authoring, accessible non-destructive workflows, and high-performance 2D, 3D, pixel and voxel creation. Each product must work independently. Future integration uses explicit, versioned, permission-controlled interfaces across separate repositories.

ATLAS should understand an authorized project's real versions, files, conventions and dependencies. Coding assistance should deliver complete, formatted, copy-ready code with exact paths, insertion or replacement points, imports, editor setup, configurable parameters, integration steps, build and validation commands, and an account of untested behavior. This applies to Unreal C++ and Blueprints, UEFN Verse, Unity C#, Blender Python, C/C++, C#/.NET, JavaScript/TypeScript, HTML/CSS, Rust, Python and future PLATZ programming and visual behavior systems. Approved edits should preserve existing work, validate changes in isolation and support reliable rollback.

Project and job specialists should start with scoped knowledge, reusable procedures, project conventions and verified outcomes in coding, game development, research, writing, sprites, characters and 3D assets. Train compact ATLAS-original specialists only when eligible evidence and independent measurements justify their cost. The long-term objective is useful local reasoning with increasing independence from external pretrained models.
